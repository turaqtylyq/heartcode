# HEARTCODE — публичная демоверсия

Мобильный адаптивный прототип HEARTCODE в утверждённом стиле **Soft Gradient** (фиолетовые/лавандовые градиенты).

## Что входит
- Главная с приветствием по имени (демонстрационное имя хранится только в браузере).
- Каталог 4 модулей.
- Страница первого модуля и два демонстрационных экрана уроков.
- Разделы прогресса и профиля.
- Адаптивная навигация на смартфоне и компьютере.

## Важно
Это **публичный прототип**, а не закрытая система для студентов. Авторизации, серверной базы данных, защиты видео и подлинного прогресса пока нет. Оригинальные YouTube-ссылки на платные видео, учебные PDF и ссылки на закрытые сообщества в демоверсию не добавлены. Не храните здесь персональные данные студентов и не загружайте платные материалы.

## Публикация в GitHub Pages
1. Откройте `Settings → Pages` в этом репозитории.
2. В разделе `Build and deployment` выберите `Deploy from a branch`.
3. `Branch: main`, папка `/(root)`.
4. Нажмите `Save`.

Ожидаемый адрес после успешной публикации:
https://turaqtylyq.github.io/heartcode/

Проверяйте реальный статус на странице `Settings → Pages`; наличие файлов в репозитории само по себе не означает, что GitHub Pages опубликован.

## Развитие
Сначала согласовать дизайн и маршруты первой версии, затем подключать защищённый доступ к видео, файлам и профилям студентов через серверную архитектуру. GitHub Pages сам по себе авторизацию не обеспечивает.
