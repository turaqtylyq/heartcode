# HEARTCODE — Tilda лендинг

Оригинальный учебный сайт репозитория **не изменён**. Это отдельная папка для лендинга вебинара.

1. Откройте [T123_READY.html](T123_READY.html), нажмите **Raw**, скопируйте весь код.
2. В Tilda: страница → блок T123 → Контент → вставьте код → Сохранить → Опубликовать.
3. Изображения из папки assets уже подключены по HTTPS GitHub Raw.
4. Проверьте опубликованную страницу на телефоне и работу кнопки регистрации.

**Важно:** подключение Google Sheets в Tilda не распространяется автоматически на формы HTML внутри T123. Для реальной записи в таблицу используйте форму Tilda или явно подключённый обработчик и проверьте тестовую отправку. WhatsApp-ссылку подключите отдельно.

HEARTCODE — Өмірді бірге құтқарайық!
